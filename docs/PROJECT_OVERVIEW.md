# Project Overview: Personal Developer Portfolio

## 1. Project Introduction
This project is a modern, high-performance, and visually distinctive personal developer portfolio website built using **Next.js (App Router)** and **TypeScript**. The portfolio serves as the definitive digital presence for **Lalit Bisht**, presenting engineering expertise in Full-Stack Web Development, AI-Powered Applications (Google Gemini API), REST APIs, Database Architecture, and Data Analysis. It showcases his professional role as **Software Developer Intern at Technogetic Pvt Ltd.**, his featured production-grade projects, technical capabilities, academic background at DIT University (MCA, 8.23 CGPA), NIELIT 'A' & 'O' Level certifications, and sports leadership honors (Two-time Runner Up in Sphurti Basketball Championship) to recruiters, engineering managers, tech leads, and potential collaborators.

---

## 2. Main Objectives
* **Make a Lasting Impression:** Deliver an elite first impression with refined visual aesthetics, modern typography, fluid micro-interactions, and flawless responsiveness.
* **Demonstrate Engineering Depth:** Go beyond generic portfolio cards by showcasing architectural decisions, problem-solving abilities, and technology choices.
* **Recruiter & Hiring Manager Focused:** Provide clear, frictionless navigation, fast content scanning, instant access to resume downloads, GitHub repositories, and live project demos.
* **Peak Performance & Modern Standards:** Achieve near 100/100 Google Lighthouse scores across Performance, Accessibility, Best Practices, and SEO.

---

## 3. Target Audience
1. **Technical Recruiters & Talent Acquisition:** Looking for quick skill validation, resume access, experience timeline, and contact options.
2. **Engineering Managers & Tech Leads:** Evaluating code architecture, project complexity, problem-solving depth, and visual attention to detail.
3. **Clients & Freelance Partners:** Assessing capabilities, reliability, delivered solutions, and professional communication.
4. **Developer Community:** Exploring open-source contributions, engineering write-ups, and interactive experiments.

---

## 4. Personal Branding Strategy
* **Archetype:** "Modern Software Engineer & Product Builder" — an engineer who bridges solid backend logic with exceptional frontend craft and modern tools (AI, cloud, modern web).
* **Tone & Persona:** Professional, confident, articulate, engineering-driven, and forward-thinking.
* **Visual Identity (Reference: Sumit Chaubey):** Modern minimalist, deep zinc dark canvas (`#09090B`), sleek subtle card borders (`border-zinc-800`), crisp neo-grotesque typography, emerald status beacons (`#10B981`), and purposeful, non-distracting micro-interactions.

---

## 5. Core Features
* **Interactive Hero Section:** Bold headline, dynamic status badge (*"Available for New Opportunities"*), role breakdown, quick CTAs, and social links.
* **Curated Project Showcase:** Bento-grid / interactive cards highlighting core projects with architectural context, tech badges, live demo links, and GitHub links.
* **Comprehensive Skill Matrix:** Categorized technical competencies (Languages, Frameworks, Cloud/Databases, Developer Tools) with clean iconography and proficiency indicators.
* **Interactive Experience & Journey Timeline:** Chronological progression of professional roles, internships, or educational milestones.
* **Interactive Contact Section:** Clean contact form with validation, direct email copy-to-clipboard, social links, and optional calendar booking.
* **Responsive & Adaptive Navigation:** Floating glassmorphic dock/navbar with smooth scroll spies and mobile drawer.
* **SEO & Social Share Ready:** Next.js Metadata API, OpenGraph social preview cards, JSON-LD structured data.

---

## 6. Expected User Experience (UX)
* **Zero Layout Shift:** Instant page loading with skeleton states and optimized web fonts.
* **Intuitive Scannability:** Recruiters can scan the most crucial data (Skills, Projects, Resume) within 15 seconds.
* **Meaningful Micro-Interactions:** Hover states on cards, subtle magnetic buttons, smooth spring scroll animations without lag.
* **Accessibility First:** Semantic HTML5, WCAG AA color contrast, full keyboard navigation, and reduced-motion mode.

---

## 7. Technology Overview
* **Framework:** Next.js (App Router, React Server Components)
* **Language:** TypeScript (Strict Mode)
* **Styling:** Tailwind CSS + CSS Variables for tokens
* **Animations:** Framer Motion (micro-interactions & scroll triggers)
* **Icons:** Lucide React
* **Typography:** `next/font` (Geist Sans / Inter + Geist Mono / JetBrains Mono)
* **Deployment:** Vercel / Cloudflare Pages
